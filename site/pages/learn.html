Learn

A ladder of small programs, from your first commands to a ProDOS 8 program you build on maux and test on the bare machine with bye.

A lesson is on this site only because check-examples has typed it on the machine, a key at a time, the way you will, and asserted what the screen shows. The session on each page is the one that passed; the code on each page is the file that was typed. Run the same lessons yourself on the release disk: every file is in /usr/src/examples.

The ladder

{{gen:ladder}}

The sources live in the tree under examples/ and are staged on the release disk under /usr/src/examples, so you can read them on the machine. All lesson sources follow the house assembler dialect: 64-character lines, 13-character labels, ASCII, no macros.

Typing the lessons found things that do not work yet, in the shell. They are reported to the release and not yet fixed; the pages that meet them say so, plainly, and the lessons are written to avoid them. The L4 page, on shell scripting, has the list.

Meanwhile: watch a demo, read the manual, or see the developer notes.
