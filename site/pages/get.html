Try it in your browser

Boots this disk in Apple2TS, an Apple II emulator in your browser. Type at a human pace: it is a IIe keyboard.

{{gen:tryit}}

Run it

In an emulator

mame apple2ee -aux rw3 -sl7 a2sd -hard maux-VERSION.po

That sets up an enhanced IIe with a RamWorks III and the disk on an AppleIISd card. Add a Mouse or Mockingboard card for the 60 Hz clock tick; you supply the Apple ROMs.

On an Apple IIe

You need an enhanced IIe, a RamWorks-style card with at least {{fact:min_ram_kb}} KB, and a SmartPort card that can present a {{fact:release_mb}} MB volume (an SD or CompactFlash adapter). Write the disk to the card's media byte for byte, for example dd if=maux-VERSION.po of=/dev/rdiskN bs=1m, then boot from that slot. Nobody has run it on real hardware yet.

Quick start

  1. Boot. You land at the shell prompt.
  2. Run ls /bin to see the commands, and ps to see the processes.
  3. Run man man to learn the manual; q leaves it.
  4. Next, Learn to write a program, or Watch it run.

Requirements

  • An enhanced Apple IIe (65C02)
  • A RamWorks-compatible card with at least {{fact:min_ram_kb}} KB, presenting banks $00 to $0F — the kernel does not probe, it uses those sixteen and no others. A fully populated main board gives exactly them. {{fact:min_ram_kb}} KB reached any other way (say a part-filled board plus an expander) can leave gaps in that range, and bank select is write-only, so maux will hand a process a bank that is not there without noticing.
  • An AppleMouse or Mockingboard card, for the clock tick
  • A SmartPort card that can present a {{fact:release_mb}} MB volume

Or an emulator: MAME, or Apple2TS in your browser.

Optional

  • A Videx UltraTerm, for an enhanced terminal: more screen modes and hardware scrolling
  • A Super Serial Card, to tip in and out of another machine

Limits

Single user, no memory protection, no network stack and no C compiler. Only emulator runs are on record so far.
