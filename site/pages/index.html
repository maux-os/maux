Not Unix-like. A real Unix.

Develop on your Apple IIe like a PDP-11 is in the next room. maux brings a POSIX-adjacent toolset to your expanded Apple IIe.

  • Self-hostingA full assembler toolchain plus native PLASMA support — and it rebuilds itself: a make run inside maux produces the utilities and the {{fact:selfrebuild_kernel_k}}k kernel, byte for byte identical to the host-side cross-assembler’s output.
  • Power tools for power users{{fact:utility_count}} commands and {{fact:man_pages_total}} manual pages: a Bourne-compatible shell with job control, grep, find, sed, vi, make, as and ld.
  • Modern conveniencesFour virtual consoles, command history, line editing and tab completion.
  • Checked against POSIX{{fact:cf_util_total}} differential tests run maux’s tools against the real ones on macOS and Linux, and the {{fact:cf_util_gaps}} known differences are named, not hidden.
  • RequirementsAn enhanced IIe with {{fact:min_ram_mb}} megabyte of auxiliary memory and a Mouse or Mockingboard.
