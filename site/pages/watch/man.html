The gate that proves it

This film is made by site/demos/man.py. Run as assertions, the same file is {{gen:demogate}}, and it runs with the rest of the tests. It requires that the title row is the first line of the page, that the second page starts one screenful on, that the search puts the matching line on the top row, and that after q the shell screen is back untouched. The rows are computed on the host from the bytes of the manual page on the image. The checks themselves were tested: with more replaced by a copy of cat, or man by true, the demo fails at "the first page is up".
