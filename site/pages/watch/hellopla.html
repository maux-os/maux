A program in PLASMA, written and built without leaving the machine, and then run twice: loaded the ordinary way, and as a single file made by the plasma cutter. The demo types David Schmenk's own hello.pla in vi, writes a Makefile in vi, runs make, which compiles it with plasm, and runs the module with plasma. Then make again, which has nothing to do, and the same program from the plasma cutter.

The two startups

Each run is timed in cycles of the emulated machine, from the moment RETURN is pressed to the moment the output appears on the screen. The first, plasma hello.mod, loads the runtime, reads the module and resolves its names. The second is a copy of the cut program from /usr/src/examples/HELLOPLA/HELLO: that file was made on the host by plascut, which did the loading once, in advance. Both are run once cold and the cut one again warm; the captions give the figures this run measured, and they differ a little between the two displays. The plasma cutter is described on the Dev page.

{{gen:hellopla_figures}}

A TAB, not eight spaces

The Makefile is typed with real TABs. It removes the old module, runs plasm and lists the new one, because plasm exits with success even after a compile error and ls fails when the module is missing, which stops make.

The source is his

The program is src/samplesrc/hello.pla from PLASMA, written by David Schmenk (MIT licence, Copyright © 2010-2022 David Schmenk), unchanged. The lines the film types are compared with the lesson's file, exactly, and the lesson's file is checked against his at the PLASMA version maux builds with.

The gate that proves it

This film is made by site/demos/hellopla.py. Run as assertions, the same file is {{gen:demogate}}, and it runs with the rest of the tests, on both displays. It requires that the lines typed are those of the lesson's hello.pla and Makefile exactly; that cat reads both files back as typed; that cmp finds the typed hello.pla identical to the file on the disk; that make prints the commands and plasm's report in order and 23 bytes compiled; that plasma hello.mod and the cut ./hello both print Hello, world.; that the cut program, started cold, takes fewer cycles than plasma hello.mod started cold, and started again warm fewer than started cold; that cmp finds the copy of the cut program identical to the file on the disk; that the module the machine compiled is, but for the numbering of its imports, the module the host compiler writes; and that the host, reading the disk the machine wrote, finds hello.mod to be a REL file and hello a BIN file whose aux_type is $0800.
