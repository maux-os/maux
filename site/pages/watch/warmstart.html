The second time is faster

Every process lives in a bank of its own. When one exits, the kernel does not free its bank: it keeps it, tagged with the file whose code is in it. Launch that file again and the same bank is handed back, code intact. The film runs vi twice, and a copy of the assembler nas three times, and times each launch.

The three states

A cold launch opens the file, reads it from the disk and copies the image into a bank. A warm launch finds a kept bank tagged with that file, and skips all three. What it still pays for is the kernel's own work in starting a process, one call to ask the disk for the file's date, a page of zeros, and the program itself, which starts again from its first instruction: vi still draws its screen, and nas still prints its usage. So the saving is the load, and the more a program does after it starts, the smaller a share the load is.

A kept bank is tagged with an absolute path, so a copy of a file is a new file. It is also dropped when the file is written, and the kernel checks the file's date before it reuses one; the last launch in the film comes after cp rewrote the file, and is cold again. A kept bank is only kept until some other program needs the memory: then the oldest one is taken back.

The gate that proves it

This film is made by site/demos/warmstart.py. Run as assertions, the same file is {{gen:demogate}}, and it runs with the rest of the tests, on both displays. It requires that vi comes up on a new file and the copy of nas prints its usage line on every launch; that the second launch of vi takes fewer cycles than the first; that the first launch of the copy costs more than twice its second; and that the launch after cp rewrote the file costs more than twice the warm one. Each figure in a caption is the figure the run measured, and the stamp of the film is held to the caption that states it. The checks themselves were tested: a variant that rewrites the file just before the warm launch fails at the order of the figures, and with nas replaced by a copy of cat it fails at "asm, cold: the output never appeared".
