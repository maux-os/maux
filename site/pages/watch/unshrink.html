Thirty years of Apple II software lives in ShrinkIt archives. This one is real, a 1990 freeware utility fetched from the asimov.net mirror. The demo lists it with nulib2 -v, unpacks it with nulib2 -x, lists the files, and reads the documentation with more.

The gate that proves it

This film is made by site/demos/unshrink.py. Run as assertions, the same file is {{gen:demogate}}, and it runs with the rest of the tests. It requires that the machine’s listing agrees with an independent reader of the archive on every name, type, size and auxiliary type; that the directory after unpacking holds exactly the archive’s files; that cksum of an unpacked program and an unpacked text file, both stored compressed (LZW) in the archive, equals the host’s checksum of the archive’s own bytes; and that the documentation text comes out row for row. The checks themselves were tested: with nulib2 replaced by a copy of true the listing is empty; with one byte flipped inside the compressed stream nulib2 reports a damaged stream and the demo fails at "nulib2 -x says nothing"; with cksum or more replaced by true the checksum and the text rows fail.
