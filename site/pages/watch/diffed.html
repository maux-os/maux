The diff is the program

Watch / diffed

{{gen:player}}

diff -e does not describe a change, it is the change: a script of ed commands, last line first. The demo makes a changed copy of a manual page, writes the edit script, hands it to ed, and shows that cmp — which said the files differ a moment ago — now says nothing. This is how changes were distributed before there was a patch.

The gate that proves it

This film is made by site/demos/diffed.py. Run as assertions, the same file is {{gen:demogate}}, and it runs with the rest of the tests. It requires that the host finds exactly four changed lines between the two files; that cmp first says they differ; that the script holds exactly one command per changed line, bottom-up, at the line numbers the host computes from the same bytes; and that after ed both cmp and diff say nothing. The checks themselves were tested: with ed replaced by a copy of true the demo fails at "cmp says nothing"; with cmp replaced by true it fails at "cmp says A and B differ"; with diff replaced by cat it fails at "the script went to the file".
