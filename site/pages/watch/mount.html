Mount a disk image

{{gen:player}}

A disk image is just a file. mount attaches it as a block device and its volume appears under /mnt, where it can be listed, read and copied from like any disk. umount lets it go and the volume is gone again.

The gate that proves it

This film is made by site/demos/mount.py. Run as assertions, the same file is {{gen:demogate}}, and it runs with the rest of the tests. It requires that only the boot disk is mounted at first, that the image then appears as a second device mounted at its volume name, that ls shows exactly the files the image was built with, that a copy made from it survives umount, and that afterwards the boot disk is alone again. The checks themselves were tested: with mount replaced by a copy of true the demo fails at "only the boot disk is mounted"; with umount replaced by true it fails at "back to the boot disk alone"; with cp replaced by cat it fails at "cp prints nothing".
