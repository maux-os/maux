About as canonically Unix as a command line gets. find walks the manual, a glob picks the pages whose names begin with S, and -exec runs grep -l on each of them, one process per page, to say which mention a word.

The gate that proves it

This film is made by site/demos/findexec.py. Run as assertions, the same file is {{gen:demogate}}, and it runs with the rest of the tests. It requires that find lists exactly the pages whose names begin with S, and that the -exec run names exactly the pages that mention the word. Both lists are computed on the host from the image. The checks themselves were tested: with grep replaced by a copy of true the demo fails at "only the pages that mention the word are named"; with find replaced by true it fails at "find lists every page".
