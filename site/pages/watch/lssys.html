The program knows nothing of maux

LS.SYSTEM calls the ProDOS MLI at $BF00 and the monitor ROM's COUT, and nothing else. It finds its own prefix, opens the directory like a file, reads it a block at a time, and walks the entries: the high nibble of an entry's first byte is its storage type and the low nibble its name length. That is the ProDOS 8 of 1983, not a maux API, so the same file runs on a stock ProDOS 2.4 disk with no maux on it anywhere — which is how it is also tested.

It writes the names it found to a file called GOT, in maux's own text convention: high bit set, each line ended by $8D. So maux's tools read what ProDOS wrote with no conversion step in between. GOT is created only after the directory has been read, so it never lists itself.

One screen, two owners

Watch the picture change shape when the farewell prints. maux runs the console at 80 columns; bye puts the machine back the way a ProDOS program expects to find it — text mode, page 1, no 80STORE, 40 columns, and the display handed back to the motherboard — because a program written in 1983 is entitled to assume all of that. The 40-column screen in the middle of this film is not a rendering choice. It is the machine the tenant actually gets.

That is also why this is the one film here with a single display. Every other demo is filmed twice, on the IIe's own 80 columns and on a Videx UltraTerm. During the handover the card is not the selected display at all, so a card film would freeze on the farewell for the whole of the interesting part.

The Makefile is the test

The lesson's test rule is four lines: delete GOT, run mkwant (which is just ls | tr a-z A-Z > WANT, maux's own listing), bye LS.SYSTEM, and run check, which sorts both files and cmps them. Two programs that share no code, on two operating systems, list the same directory and are made to agree about it. The exit status of make is the verdict.

The gate that proves it

This film is made by site/demos/lssys.py. Run as assertions, the same file is {{gen:demogate}}, and it runs with the rest of the tests. It requires that the copied directory holds the lesson's own files, in the order ls prints them; that the Makefile on screen is the lesson's, line for line, tabs included; that make prints the nas command, nas's report and the ld command, in that order, and nothing else; that ls -l calls the result SYS; that the names ProDOS printed appear on the 40-column page while the tenant owns the machine; that the rows of make test come back in order, ending in sh check, with an exit status of 0; that GOT and WANT each hold exactly the expected names; and that the host, reading the disk the machine wrote, finds GOT to be maux text — every byte with its high bit set, every line ended by $8D.
