The oldest program, written and built without leaving the machine. The demo makes a directory, writes hello.s in vi, writes a Makefile in vi, runs make, which assembles with nas and links with ld, and runs the result. Then make again, which has nothing to do, and ls -l.

A TAB, not eight spaces

make wants a real TAB character before each command line, and vi on the machine inserts one when it is sent one. The film types the Makefile with those TABs, and make then runs the two commands it names, which would not happen with spaces: make running is the check that the TAB is real. (cat and the file's size are no proof, since a TAB is one byte and shows as eight columns, and the film's own text is what they are compared with.) The Makefile is the lesson's, less its comment line, including its clean rule.

The short source

The program is the one in the first assembly lesson, less its comment header, which nobody wants to watch typed. ext names two routines, PUTS and EXIT, which ld -l a pulls out of liba, maux's C-less libc. The linker puts the module first, at $0800, and writes the program as a BIN file whose aux_type is that load address.

The gate that proves it

This film is made by site/demos/hello.py. Run as assertions, the same file is {{gen:demogate}}, and it runs with the rest of the tests, on both displays. It requires that the code and data lines typed are, token for token, those of the lesson's hello.s and that the Makefile's lines are, exactly, those of the lesson's Makefile: what is typed is checked against the lesson's own files; that cat reads both files back exactly as typed; that make prints the nas command, nas's report, and the ld command, in that order; that ./hello prints hello, world; that a second make prints nothing; that the host, reading the disk the machine wrote, finds hello to be a BIN file whose aux_type is $0800; and that ls -l shows hello as BIN, hello.o as $F8, and the two text files with exactly the bytes typed.
