# scripts/encoding_census.txt -- every program in src/bin classified
# against FOREIGN text (low ASCII, $0D line ends: what NuFX, a2til, tip
# and ProDOS software deliver); checked by scripts/check_encoding_census.py
# (make check-encoding-census; docs/ENCODING-CENSUS-NOTES.md).
#
# Candidates are DERIVED, not listed here: the Makefile's UTILS plus every
# top-level src/bin manifest (not `put` by another bin file).  A program
# with no line below fails the gate; so does a line naming no program.
#
# Format (fields split on `|`):
#   NAME covered | ROW COMMAND | reason
#       ROW COMMAND is the exact FOREIGN_OK command in check_encoding.py
#   NAME exempt  | reason       (does not read text line-wise)
#   NAME broken KIND | statement  defect KNOWN and REPRODUCIBLE: check_encoding.py
#       KNOWN_BROKEN pins the exact broken output, so a FIX turns that gate red
#       and forces this line out (then: FOREIGN_OK row, flip to covered)
#   NAME gap KIND | statement   (nothing to assert yet)  KIND = terminator|polarity|both|unverified
#       terminator = line-end predicate; polarity = separator/content
#       twin (argv high-bit vs file low); a static audit hit is a
#       SUSPECT, not a proven defect.  A gap closes by gaining a
#       FOREIGN_OK row and becoming `covered`.  MAX_GAPS in the gate is a
#       ratchet on the count.
