# scripts/open_census.txt -- every SC_OPEN call site in src/bin and
# src/liba, classified (docs/OPEN-RW-2.md item 6; checked by
# scripts/check_open_census.py).  Format:  FILE  LABEL  ro|append|none  REASON
#   ro   the parmlist count byte is OPEN_RO: the site only READS through
#        its fd, so it may share a file with one writer
#   append  the count byte is OPEN_APPEND (OAPPEND-1): every write
#        through the fd lands at EOF, so any number of appenders may
#        share the file; the site must be a pure appender
#   none no intent declared: the site may write, or has not been proven
#        read-only (an open is write-capable until it says otherwise)
# LABEL is the parmlist loaded before the call; a second call on the
# same label in one file is LABEL#2.  A new SC_OPEN site fails the
# gate until it is listed here.
